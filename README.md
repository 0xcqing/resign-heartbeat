This program sends one resignation letter of the heartbeat job an agent runs, as the whole entry and nothing else. It writes that single line to `entry.txt` in the output directory and fails loudly if the line is empty, too long, multi-line, padded, double-spaced, or does not read back byte-for-byte.

## How it runs

```bash
MAKEFUN_OUTPUT_DIR=./out node --experimental-strip-types main.ts
```
